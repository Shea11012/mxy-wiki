# 智能体通信协议（总览）

> 源文摘要：HelloAgents 第十章引入三种通信协议——MCP（智能体与工具标准化通信）、A2A（智能体间点对点协作）、ANP（大规模智能体网络），通过三层架构（协议实现层→工具封装层→智能体集成层）统一封装为 MCPTool/A2ATool/ANPTool。

## 拆分页面

- [[MCP协议与自定义服务器]] — MCP 三层架构（Host/Client/Server）、核心能力（Tools/Resources/Prompts）、5 种传输方式、构建自定义 MCP 服务器
- [[A2A协议]] — 智能体间对等通信、任务卡片（Task Card）协商、A2ATool 使用
- [[ANP协议]] — 去中心化服务发现、AgentCard 注册、ANPTool 网络管理

## 选择指南

- **MCP**：智能体需要访问外部服务（文件、数据库、API）
- **A2A**：多个智能体相互协作完成任务
- **ANP**：构建大规模智能体生态系统
