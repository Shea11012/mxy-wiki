# 序列

python 内置多种序列（sequence），序列是一种数据结构。

列表、字符串和元组都属于序列。其中元组和字符串是不可变的（一旦创建内容就是固定的）

**Tips： 要将字符列表转换位字符串，可以使用表达式 `''.join(list('Hello'))`**

### 切片

```python
numbers = [1,2,3,4,5,6,7,8]
numbers[1:5:2] # 对应起始索引，结束位置，步长，结束位置和步长支持负值，负值将会从后往前输出
```
