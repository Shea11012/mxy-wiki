窗口函数会对数据进行分组，每个分组都是一个窗口。与聚合函数不同，窗口函数会对窗口中每一条记录进行应用。有点类似滑动窗口的概念

# 基本语法

```mysql
window_function() over(
[partition by `字段1`,`字段2`,...]
[order by `字段3`,`字段4`]
[frame_clause]
) as `别名`
```

## over

用于标识使用窗口函数
- over()：常规用法
- over window_name：由 from 后面的 window 子句定义窗口规范，可重复使用

## partition by

用于将记录划分为不同的分区，窗口函数在每个分区上分别执行

## order by

将每个分区中的记录进行排序，窗口函数将按照排序后的顺序进行计算

## frame clause

用于指定每个分区的数据范围

# 进阶语法

## 命名窗口

```mysql
-- 定义了三个命名窗口，其中第二个和第三个都引用了第一个，这样每个窗口就可以根据不同的范围来计算累计和
SELECT 
	sale_amount,
	SUM(`sale_amount`) OVER w1 AS sum_amount1,
	SUM(`sale_amount`) OVER w2 AS sum_amount2,
	SUM(`sale_amount`) OVER w3 AS sum_amount3
FROM `salse`
WINDOW 
	w1 AS (ORDER BY `sale_amount`),
	w2 AS (w1 ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW),
	w3 AS (w1 RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW);

```

## frame clause

通过 frame_clause 显示定义框架范围，指定每个分区内应用窗口函数的一小部分数据的区域，可根据当前行动态的变化，或者选定一个静态的范围
```mysql
frame_units frame_extent
```
frame_units：
- rows：基于物理行数
- range：基于逻辑值范围

frame_extent：
- current row：当前行
- unbounded preceding：分区中第一行
- unbounded following：分区中最后一行
- n preceding：当框架单位是 rows 时，边界是当前行的前 n 行
- n following

range 在 n preceding 的示例

```mysql
SELECT 
    id,
    sale_date,
    amount,
    -- RANGE: 当前行和金额差值在200以内的所有前行
    AVG(amount) OVER (ORDER BY amount 
                      RANGE BETWEEN 200 PRECEDING AND CURRENT ROW) as avg_range
FROM sales
ORDER BY amount;
```

过程
```
行1: amount=100
     RANGE: 金额在[100-200, 100]即[-100, 100]范围内的行 → AVG(100) = 100

行2: amount=150  
     RANGE: 金额在[150-200, 150]即[-50, 150]范围内的行 → AVG(100,150) = 125

行3: amount=150
     RANGE: 金额在[150-200, 150]即[-50, 150]范围内的行 → AVG(100,150,150) = 133.33

行4: amount=200
     RANGE: 金额在[200-200, 200]即[0, 200]范围内的行 → AVG(100,150,150,200) = 150

行5: amount=250
     RANGE: 金额在[250-200, 250]即[50, 250]范围内的行 → AVG(100,150,150,200,250) = 182
```
